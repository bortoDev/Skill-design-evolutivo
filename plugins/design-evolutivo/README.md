# design-evolutivo (plugin)

Plugin per Claude Code con una sola skill, `design-evolutivo`: progetta, rivede, corregge e valuta interfacce e impara dal gusto di chi la usa, da un progetto all'altro. La skill lavora in italiano.

- Installazione, da una sessione di Claude Code:

  ```
  /plugin install design-evolutivo --marketplace bortoDev/Skill-design-evolutivo
  ```

- Permessi, aggiornamenti e alternativa senza plugin: [guida completa](skills/design-evolutivo/README.md).
- Presentazione del progetto: [README in inglese](../../README.md) · [README in italiano](../../README.it.md).
- La memoria che la skill costruisce usandola sta in `~/design-evolutivo-memoria/`, fuori dal plugin: aggiornare o disinstallare il plugin non la cancella.
