# Catalogo degli errori
Si legge a ogni correzione e in verifica (osservazioni). Una classe è una **firma** (la tendenza: lo stesso effetto sbagliato), non un punto della pagina; le cause si annotano per occorrenza. Procedura: `processo/evoluzione.md` §6.

## Formato di una classe
```
## E-NNN · titolo breve
Stato: osservazione | regola (R-…) | ritirata · Livello: L1–L5 · Ambito: … · Occorrenze: N · Ultima: AAAA-MM-GG
Firma: Tendo a … · Cause: C… (una o più, dalle occorrenze)
Segnali: come riconoscerlo in un file o in una schermata
Occorrenze:
- F-… (progetto, data): istanza · causa C… · "parole dell'utente"
Contro-esempio: caso simile che NON è questo errore
Collegate: E-…
```
